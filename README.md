# 📸 Aurelia Lens Photography

**Capture Moments. Create Memories.**

Aurelia Lens Photography is a beautiful and responsive photography website designed to showcase photography services, creative work, and memorable moments.

The website provides visitors with an elegant platform to explore photography collections, learn about the photographer, view available packages, and get in touch for bookings.

## ✨ Features

- **Home Section:** Attractive landing page with a photography introduction.
- **About Section:** Introduction to the photographer.
- **Photography Gallery:** Displays beautiful photography collections.
- **Services Section:** Showcases available photography services.
- **Packages Section:** Presents photography packages.
- **Contact Section:** Provides contact information for enquiries.
- **Responsive Design:** Designed to work on desktop, tablet, and mobile screens.
- **Modern UI:** Clean layout with attractive styling and visual elements.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `aurelia_lens_photography_live_preview.html`.
4. Run the file in your web browser.
5. Explore the photography website.

## 🎯 Project Objective

The main objective of this project is to develop an attractive and user-friendly photography website using HTML and CSS. It demonstrates basic web development concepts, webpage structure, styling, and responsive design.
